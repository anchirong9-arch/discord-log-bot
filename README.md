# 🛡️ 백수톡 로그봇

디스코드 서버에서 일어나는 일을 **비공개 `#서버-로그` 채널**에 차곡차곡 남기는 봇입니다.
사진·파일은 **원본 그대로 다시 첨부**해서, 원래 방에서 메시지를 지워도 로그 방에는 남아 있습니다.

---

## 무엇을 남기나

| | 남기는 것 |
|---|---|
| 📎 | **사진·파일 원본 보존** — 올라온 파일을 즉시 내려받아 `#서버-로그`에 원본 그대로 다시 첨부 (25MB 초과는 링크로 남김) |
| 🗑️ | **메시지 삭제** — 작성자, 채널, 삭제 전 본문, 첨부돼 있던 파일까지 재첨부 |
| ✏️ | **메시지 수정** — 수정 전 / 수정 후 내용, 메시지 바로가기 |
| ✅ | **멤버 입장** — 계정 만든 날, 현재 멤버 수 |
| 👋 | **멤버 퇴장·추방** — 들어온 날, 가지고 있던 역할 |
| 🚫 | **멤버 차단(밴)** |
| 👤 | **닉네임·역할 변경** |
| 🎧 | **음성 채널** — 입장·퇴장·방 이동·마이크/헤드셋/화면공유/카메라 상태 |
| 📁 | **채널** — 생성·삭제·이름/주제/슬로우모드/카테고리 변경 |
| 🎭 | **역할** — 생성·삭제·이름/색/권한 변경 |

봇 자신의 메시지와 `#서버-로그` 채널 안의 메시지는 기록하지 않습니다(무한 반복 방지).

---

## 1️⃣ 봇을 서버에 초대하기

아래 링크를 클릭 → 서버 선택 → **승인** 을 누르면 봇이 `백수톡`에 들어옵니다.

__INVITE_URL__

> 요청하는 권한은 **채널 보기 / 메시지 보내기 / 링크 임베드 / 파일 첨부 / 메시지 기록 읽기 / 감사 로그 보기** 6개뿐입니다.

서버에 들어온 봇은 자동으로 `#서버-로그` 채널에 글을 남깁니다.

---

## 2️⃣ 윈도우에서 켜기 (가장 쉬움)

1. 이 폴더에서 **`실행하기.bat` 더블클릭**
2. 처음 한 번만 **봇 토큰**을 물어봅니다. 붙여넣고 Enter.
   - 토큰은 https://discord.com/developers/applications → **백수톡 로그봇** → **Bot** → **[토큰 초기화]** → **[비밀번호 사용]** → 디스코드 비밀번호 입력 → 나오는 문자열
   - `.env` 파일이 자동으로 만들어지고, 로그 채널(`1572390727042727976` = `#서버-로그`)도 자동으로 들어갑니다.
3. 봇이 켜집니다. **검은 창을 닫으면 봇이 꺼지니** 켜 둔 채로 쓰세요.

---

## 3️⃣ 컴퓨터를 꺼도 24시간 돌게 하기 (무료 클라우드)

### Render.com (추천 · 무료 Web Service)

1. https://render.com 가입 (GitHub 계정으로 로그인)
2. **New → Blueprint** → 이 저장소(`anchirong9-arch/discord-log-bot`) 선택
3. `render.yaml` 이 자동으로 읽혀요. **DISCORD_TOKEN** 값만 붙여넣고 **Apply**
4. 몇 분 뒤 상태가 **Live** 가 되면 끝. 봇이 24시간 켜져 있습니다.

> 무료 플랜은 15분간 요청이 없으면 잠들었다가 다시 깨어납니다.
> 봇은 켜져 있는 동안 계속 디스코드와 연결을 유지하므로 실제로는 잘 자지 않지만,
> 아주 오래 조용하면 한 번 깨어나는 동안 몇 초 정도 로그가 비칠 수 있습니다.
> 확실하게 하려면 UptimeRobot 같은 무료 서비스로 5분마다 `https://<내-앱>.onrender.com/` 을 찔러 주세요(이 저장소의 봇은 `PORT` 가 있으면 상태 확인 서버를 함께 켭니다).

### Koyeb / Railway

- 시작 명령: `python bot.py`
- 환경 변수: `DISCORD_TOKEN`, `LOG_CHANNEL_ID`
- `Procfile`(`worker: python bot.py`)이 들어 있어서 그대로 인식됩니다.

---

## 4️⃣ 설정값 (`.env`)

| 이름 | 설명 |
|---|---|
| `DISCORD_TOKEN` | 봇 토큰 (필수) |
| `LOG_CHANNEL_ID` | 로그를 남길 채널 ID. 기본값은 백수톡 `#서버-로그` (`1572390727042727976`) |
| `LOG_USER_ID` | (선택) 로그를 **디엠으로도** 받을 사용자 ID. 비워 두면 안 보냄 |
| `PORT` | (선택) 클라우드에서 자동으로 들어옴. 있으면 상태 확인 서버를 함께 켬 |

`.env` 는 `.gitignore` 에 들어 있어 GitHub 에 올라가지 않습니다. **토큰은 아무에게도 보내지 마세요.**

---

## 5️⃣ 꼭 알아 둘 점

- **관리자(Administrator) 권한이 있는 역할을 가진 사람은 비공개 채널도 볼 수 있습니다.** 디스코드 규칙이라 채널 설정으로 뺄 수 없어요. 진짜 나만 보고 싶으면 `.env` 의 `LOG_USER_ID` 에 본인 ID를 넣어 **디엠 사본**을 함께 받으세요.
- **봇이 꺼져 있는 동안** 올라온 사진은 원본이 보관되지 않고, 그 사이 지워진 메시지도 기록되지 않습니다. 24시간 켜 두는 게 좋습니다.
- **25MB 를 넘는 파일**은 디스코드 봇이 다시 올릴 수 없어서 이름·크기·원본 링크만 남깁니다.
- 로그는 결국 **디스코드 안에** 쌓입니다. 채널이나 서버가 사라지면 로그도 사라지니, 정말 중요한 자료는 따로 백업하세요.
- 디스코드 정책상 **메시지 내용·서버 멤버** 권한(Intent)이 켜져 있어야 원문과 입퇴장이 기록됩니다. (이미 켜 둔 상태)
